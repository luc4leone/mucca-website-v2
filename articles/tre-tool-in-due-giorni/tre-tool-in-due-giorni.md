mi sono creato un altro strumento, **Annotando** un editor per file `txt` e `md` (per ora). negli anni ho usato molti editor di testo, alcuni:

- textEdit
- visual studio code
- devin (ex windsurf)
- cursor
- antigravity
- bear
- cotEditor
- vim
- nano
- micro

e altri 20.

ho un Macbook Air. questo il prompt che ho dato a Opus 5.5:

Creami un editor di testo per macOS chiamato Annotando, con lo stesso metodo di Dettato (~/Apps/Dettato): un solo main.swift con AppKit, niente Xcode, build.sh che compila, firma e registra l'app in ~/Apps/Annotando.

Base:
- apre e salva testo semplice, Markdown e JSON; riconosce e mantiene la codifica dei file non UTF-8
- salvataggio automatico e cronologia versioni di macOS
- ⌘N apre un nuovo documento come scheda; File → Nuova finestra (⌥⌘N) lo apre in una finestra a sé
- cerca ⌘F, cerca e sostituisci ⌥⌘F, stampa
- controllo ortografico attivo; niente sostituzione automatica di virgolette e trattini
- ⌘+ ⌘- ⌘0 per la dimensione del testo, ricordata
- menu tutti in italiano

Evidenziazione Markdown mentre scrivo: titoli, grassetto, corsivo, codice
inline e blocchi ```, link, citazioni, righe orizzontali. I simboli di sintassi (**, #, _) restano visibili ma attenuati.

Due temi, da Vista → Tema, ricordati alla riapertura:
- Chiaro: SF Mono 14, col
- Scuro: copia il tema di CotEditor che uso ora (leggilo dal suo file
.cottheme e dalle sue preferenze, font compreso) ed evidenzia la riga del cursore. Come colorare gli elementi partendo da quella palette

Scrivi un README in italiano (senza tabelle) con come si lancia, cosa fa, i file del progetto, e una sezione “Maybe next step” con cosa manca per editare bene file HTML.

Sto scrivendo questo articolo con questo editor. Perfetto... per ora :)
